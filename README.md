#### Motivation
Urbit's two orginally sins are both fundamentally tied to ID system Azimuth. Azimuth is as revolutionary as it is reactionary. 
A piece of poison pill public infrastructure meant to entrench techno-feudalism in protocol structure. Urbit's Implementation 
fundamentally was born malformed being concieved pre-blockchains, many crypto features are fundamentally after thoughts. Myco
sets out to atone for these sins, by redesigning urbit and azimuth to have a native blockchain that takes over from Ethereum in
managing Azimuth's state.

As part of this rewrite The old hierarchy of galaxy, star, planet shall be effectively abolished. Community infrastructure is just
that community infrastructure not an individual's property. As such every individual is a planet, Stars, and Galaxies are actually 
the state machines of L2's and L3's. Yes you read that right L3's. 

Running a blockchain can be an enormous load and as such the network is hyper sharded such that everyone can be expected to run a full
node as part of their ship.
